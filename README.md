# English Vocabulary & Reading Practice

英検・高校入試対策のための、英単語・熟語・長文読解の学習アプリです。ブラウザだけで動作し、スマートフォンやパソコンで壁貼り教材のように使えます。

**公開ページ：** https://egoaid.github.io/English-Vocabulary/

## できること

- 英文と日本語訳を段落ごとに対応させたリーディング教材（社会トピック・物語文・論説文・英作文・リスニング対策）
- 重要英単語 約1,900語・重要熟語 約1,000語のランク別一覧
- 英語の発音読み上げ（通常速度・ゆっくり）
- フルスクリーン暗記モード（英文をハイライトしながら音声で流し読み）
- フラッシュカードモード（単語・熟語を1枚ずつ全画面表示）
  - 覚えた単語にチェックを入れると、次回以降は自動的に省略できます
  - ランダムな順番での再生にも切り替えられます
- ダークモード、文字サイズ・余白・ハイライトの色・表示方法などを設定画面で調整可能
- スマートフォンのホーム画面に追加すると、アプリのように起動できます（オフラインでも一部利用可）

## 使い方

1. 上のリンクからページを開きます。
2. 目次からカテゴリを選び、読解問題や単語帳に進みます。
3. 画面右上の ⚙️ アイコンから、読み上げ速度や文字サイズなどをお好みに調整できます。
4. 画面左上の ☰ アイコンから、他のカテゴリへもすぐに移動できます。
5. さらに詳しい操作方法は、設定パネル内の「📖 使い方マニュアル」でも確認できます。

## 対応環境

最新版の Chrome / Safari / Edge など、主要なモダンブラウザに対応しています。音声読み上げには、ブラウザに内蔵された音声合成機能（Web Speech API）を使用します。
