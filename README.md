# English Vocabulary & Reading Practice

![English Reading Practice](icons/og-image.png)

英検・高校入試対策のための、英単語・熟語・長文読解の学習アプリです。ブラウザだけで動作し、スマートフォンやパソコンで壁貼り教材のように使えます。

**公開ページ：** https://egoaid.github.io/English-Vocabulary/

## できること

- 英文と日本語訳を段落ごとに対応させたオリジナル読解教材（社会トピック・物語文・論説文・英作文・リスニング対策）
- 日常英語に触れる「English Experiences」（日常会話・メッセージ・Eメール・人物紹介・エッセイ・インタビュー・アート・旅行紹介・科学レポート・How-to）
- 重要英単語・重要熟語のランク別一覧（英単語はランクA〜F、熟語はランクA〜Eで難易度順に整理。単語のランクFは英検準1級レベルの参考語彙）
- 英語の発音読み上げ（通常速度・ゆっくり）。ブラウザがMicrosoft Online Natural音声を提供している場合は、より自然な音声（男性・女性）を選択可能
- フルスクリーン暗記モード（英文をハイライトしながら音声で流し読み）
  - スマートフォンでは、対応端末・ブラウザで再生中の画面スリープを自動的に防止
- フラッシュカードモード（単語・熟語を1枚ずつ全画面表示）
  - 覚えた単語にチェックを入れると、次回以降は自動的に省略できます
  - ランダムな順番での再生にも切り替えられます
  - スマートフォンでは、対応端末・ブラウザで再生中の画面スリープを自動的に防止
- ダークモード、文字サイズ・余白・ハイライトの色・表示方法などを設定画面で調整可能
- PWA対応・スマートフォン対応
  - ホーム画面に追加すると、アプリのように起動できます（オフラインでも一部利用可）
  - iPhoneのノッチ／ホームバーなどのセーフエリアに対応したレイアウト
  - ホーム画面ショートカットから「重要英単語」「重要熟語」に直接ジャンプ可能

## 使い方

1. 上のリンクからページを開きます。
2. 目次からカテゴリを選び、読解問題や単語帳に進みます。
3. 画面右上の ⚙️ アイコンから、読み上げ速度や文字サイズなどをお好みに調整できます。
4. 画面左上の ☰ アイコンから、他のカテゴリへもすぐに移動できます。🏠 アイコンを押すと、いつでもホーム（目次）に戻れます。
5. さらに詳しい操作方法は、設定パネル内の「📖 使い方マニュアル」でも確認できます（アプリのバージョン番号もここに表示されます）。

## 対応環境

最新版の Chrome / Safari / Edge など、主要なモダンブラウザに対応しています。音声読み上げには、ブラウザに内蔵された音声合成機能（Web Speech API）を使用します。Microsoft Edge（Windows版・Mac版）で「Online (Natural)」音声が利用できる場合、設定パネルからより自然な音声を選択できます。

## プライバシーについて

このアプリは会員登録・ログインが不要で、サーバーにデータを送信しません。設定（文字サイズ・ダークモード・読み上げ速度・暗記済みチェックなど）は、利用しているブラウザの中だけに保存されます。
